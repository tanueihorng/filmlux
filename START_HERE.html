Filmlux · videos, made by your agent

Make a high-quality video with your coding agent.

Pick a style, a voice and music here, describe what you need, drop your files in, and let the agent produce it. You get a story, natural voiceover, music, captions, versions and quality checks, and no video editor.

1

Choose and brief

Browse the styles, voices and music below. Fill in the brief and save brief.json into inbox/. You can skip this; the agent will ask you instead.

2

Drop your files

Put anything useful in inbox/: a doc, deck, data (CSV/XLSX), images, logo, screen recordings (MP4).

3

Ask your agent

Open this folder in your coding agent (Codex, Claude Code, Gemini CLI, Cursor…) and say: "Read AGENTS.md and make my video." It confirms a brief and a script with you, shows previews, then renders.

Prefer buttons? Open Filmlux Studio

Run python studio.py app. Run python studio.py shortcut once to get a Filmlux icon on your Desktop; it works even where .bat files are blocked. It opens a local page where you can create projects, upload files to the inbox, preview stills and audio, render, and compare versions side by side, and copy ready-made prompts for your agent. It uses the same commands as the agent, so you can switch between the two at any time.

Pick a style

Motion and transitions

    
Every theme moves in its own way, and you can change it. Motion is how things arrive: real spring physics (as in Remotion), mask reveals, typewriter, stop-motion, focus pulls, slams. Transitions are how one scene becomes the next: fade, slide, wipe, flip, clock wipe, iris, cube, zoom, flash, glitch and more. Ask your agent for one, or set "motion" and "transition" in project.json.

FAQ

    
What do I need installed?
Windows or macOS, Python 3.10+, and Microsoft Edge or Google Chrome. Then, in this folder:

      
    
        
  • Windows: pip install -r requirements.txt, then python studio.py check
    • 
        
  • macOS (Terminal): python3 -m pip install -r requirements.txt, then python3 studio.py check
    • 
      

      
The agent does this for you. On macOS, type python3 wherever these pages say python.

    
Does it work on a Mac?
Yes. Everything runs the same on macOS, using Chrome or Edge for Mac. Run python3 studio.py shortcut once to get a Filmlux icon on your Desktop: double-click it to open the app, and keep the Terminal window it opens running while you use the app.

    
Does it need the internet?
Only for the voice, the first time each line is spoken (Microsoft's speech service). Lines are cached after that. Everything else runs offline on your machine.

    
Can it use my screen recordings, slides or data?
Yes. Screen recordings become zooming, highlighted demo scenes (release film). Slides and screenshots become image or split scenes. CSV/XLSX numbers become animated charts, using your real figures only.

    
How do I change something after the first version?
Just tell the agent what you'd like, as a viewer would: "too fast here", "bigger title", "calmer voice". It re-renders as v2, v3 and so on, and never overwrites.

    
Is the music safe to use?
Yes. It is synthesised by the studio, so there is nothing to license. The fonts are SIL Open Font License. Bring your own licensed track if you prefer.

    
Can it make pictures when I have none?
Optionally. Your agent can generate illustrations if it has an image tool; otherwise paste the prompts into any image app. The studio writes the exact prompts (in the theme's style, with no text, logos or real people), shows placeholders until the images exist, and checks them afterwards. See IMAGEGEN.md. It is off unless you say yes.

    
Can it do something the scene library doesn't?
Yes. The agent can write a custom HTML scene (any design, animated by time, GSAP supported) for a hero moment. See SPEC.md → html.
