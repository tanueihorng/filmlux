# Brief: Orbit 2.0 launch teaser

> **Worked example.** This shows one good way to run the brief → script → look → scorecard steps, using a fictional product (Orbit). It is a reference for the quality bar, **not a template to copy**: your film's structure, look and words should come from your user's purpose and material.

| | |
|---|---|
| **Purpose** | Make existing Orbit users want to open version 2.0 this week |
| **Audience** | Team leads and project members who already use Orbit 1 for boards; busy, watching in a Teams post or on a town hall screen |
| **Viewer's gap** | They think Orbit is "just boards". They don't know 2.0 joins boards, an assistant, weekly updates and the inbox into one workspace |
| **Key messages** | 1. Everything about a project is now in one place. 2. Updates and status are written for you. 3. Nothing gets lost: every comment becomes trackable |
| **Call to action** | Open Orbit 2.0 |
| **Length / format** | About 40 s, 16:9 |
| **Style pack** | `motion_promo` (a short launch teaser) |
| **Theme** | Chosen with the script: see the look options in `script.md` |
| **Voice** | en-US-AvaNeural at −4 % (warm, clear, not salesy) |
| **Music** | `corporate` at −27 dB |
| **Captions** | narration, the theme's default style (works on mute in Teams) |
| **Where it will be shown** | Teams channel post and the opening of a town hall |

## Source material (from `inbox/`)

| File | What it is | How it will be used |
|---|---|---|
| `release_notes.md` (fictional) | The 2.0 feature list | The four tools in the bento; the before/after list |
| `team_process.png` (fictional) | The team's weekly planning loop | Rebuilt as a `process` loop so it reads on screen |

## Constraints and sensitivities

- No customer names or real project names on screen.
- No usage numbers: the release notes have none, so the film makes no numeric claims.
